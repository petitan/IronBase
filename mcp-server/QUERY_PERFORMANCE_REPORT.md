## Query Optimization Guide

### Recommended Query Patterns

| Goal | Bad (slow) | Good (fast) |
|------|------------|-------------|
| Non-empty field | `{$exists: true, $ne: ""}` | `{$gt: ""}` |
| Has content | `{$ne: null, $ne: ""}` | `{$gt: ""}` |
| Empty field | `{$eq: ""}` | `{$eq: ""}` ✓ |
| Missing field | `{$exists: false}` | Consider sparse index |

### Why `$gt: ""` Works

1. **Lexicographic ordering:** Any non-empty string is greater than `""`
2. **Index range scan:** B+ tree efficiently finds all keys > `""`
3. **Single condition:** No need for `$exists` - index only contains existing values

---

## Lessons Learned

1. **Query rewriting matters:** Same semantic result, 196x faster
2. **Index creation is cheap:** One-time cost, permanent benefit
3. **Explain before optimizing:** Identify CollectionScan first
4. **Operator choice matters:** `$gt` is indexable, `$ne` is not
